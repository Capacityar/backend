# Archivo

Material histórico que ya no es documentación vigente. Se conserva para no perder el historial; no se mantiene actualizado.

- `superpowers/` — planes y specs generados por agentes de IA (herramienta "superpowers") durante el desarrollo de C1–C6.
- `informe-tecnico.html` — versión anterior del informe técnico. La versión vigente se publica en [Capacityar/.github](https://github.com/Capacityar/.github) (`index.html`).
- `modelos-pedagogicos/` — documentos fuente del modelo 5P y de la consigna del TP (`.docx` / `.pdf`). Movidos acá para no versionarlos en la raíz.

La documentación general del proyecto está en [Capacityar/.github/docs](https://github.com/Capacityar/.github/tree/main/docs). En `backend/docs/` quedan solo los docs técnicos.
