## 🔍 Resumen del equipo

### Mayores aciertos

| Área | Logro | Impacto |
|------|-------|---------|
| Backend | MVP funcional con 8 módulos en 27 h | Base sólida para el modelo 5P |
| Frontend | 15 páginas implementadas con React + Tailwind | Experiencia de usuario completa |
| IA | Groq + Gemini + Mock con fallback automático | Resiliencia del sistema |
| Documentación | Informe técnico, manual, stack, requerimientos v2.0 | Trazabilidad del proyecto |

### Principales dificultades

| Problema | Causa | Impacto |
|----------|-------|---------|
| Auth diferida | Priorización de funcionalidad sobre seguridad | Endpoints públicos en MVP |
| Frontend desconectado | Sin endpoints HITL implementados | Datos mockeados |
| Timeout Render 30s | Límite del free tier | Gap analysis partido en 2 pasos |
| Sin tests automatizados | Tiempo acotado | Riesgo de regresión |

3. **Épica 3** — Alertas predictivas de abandono
4. **Épica 4** — Next-unit logic con desbloqueo progresivo

> Total estimado: ~13-16 h para cerrar el modelo pedagógico completo
